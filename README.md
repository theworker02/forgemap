# forgemap

Forge filesystem map paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/forgemap/

## Install / run

```bash
git clone https://github.com/theworker02/forgemap.git
cd forgemap
node src/cli.js
node --test
```
